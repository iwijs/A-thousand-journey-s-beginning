# Project 0：从零理解 micrograd

这是一个只处理标量的自动求导引擎。它不追求性能，目的只有一个：把
`loss.backward()` 背后的计算图、拓扑排序和链式法则变成自己能解释、能验证的代码。

本项目从可运行参考实现出发，已经完成逐模块学习、手算验证、学习率对比、`sigmoid`
算子扩展和有限差分梯度检查。完整学习步骤见工作区中的
`1_每日任务指南/W2_工程实践01_micrograd完整教程.md`。

## 已实现内容

- 标量 `Value` 与动态计算图；
- 加、乘、幂、减、除、`tanh`、ReLU、`exp` 和 `sigmoid`；
- 基于拓扑排序的反向传播与多路径梯度累积；
- `Neuron`、`Layer` 和 `MLP`；
- 均方误差训练循环与梯度下降；
- 解析梯度、有限差分梯度和 MLP 参数梯度测试。

`MLP(2, [4, 4, 1])` 的参数量为：

$$
4(2+1)+4(4+1)+1(4+1)=12+20+5=37.
$$

## 学习率实验

实验日期：2026-07-30。固定 `random.seed(42)`，使用相同的四个样本、模型初始化、
`MLP(2, [4, 4, 1])` 和 200 个训练 step，只改变恒定学习率。

### 原始结果

| step | loss（lr=0.01） | loss（lr=0.08） | loss（lr=0.1） | accuracy |
|---:|---:|---:|---:|---:|
| 0 | 0.335190 | 0.335190 | 0.335190 | 75% |
| 25 | 0.080135 | 0.003522 | 0.001638 | 100% |
| 50 | 0.042928 | 0.000192 | 0.000045 | 100% |
| 75 | 0.027044 | 0.000011 | 0.000001 | 100% |
| 100 | 0.017755 | 0.000001 | 0.000000 | 100% |
| 125 | 0.011881 | 0.000000 | 0.000000 | 100% |
| 150 | 0.008050 | 0.000000 | 0.000000 | 100% |
| 175 | 0.005503 | 0.000000 | 0.000000 | 100% |
| 199 | 0.003844 | 0.000000 | 0.000000 | 100% |

`0.000000` 是保留六位小数后的显示值，表示 loss 非常接近 0，不代表数学上严格等于 0。

### 结论

- 三种学习率都让 accuracy 从 75% 上升到 100%；
- `0.01` 更新稳定，但收敛明显较慢；
- `0.08` 和 `0.1` 都快速收敛，`0.1` 在本次实验中最快；
- accuracy 达到 100% 后 loss 仍继续下降，因为 accuracy 只检查预测符号，而均方误差还会
  推动预测值接近目标值 `1` 或 `-1`；
- 结果只适用于本次数据、初始化和模型，不能推导出 `0.1` 对其他任务也是最佳学习率。

## 完成后的核心理解

1. 局部反向函数使用 `+=`，因为同一变量可能通过多条路径影响 loss，各路径贡献必须相加。
2. 反向传播需要逆拓扑序，确保节点收齐所有上游梯度后再继续传播。
3. 当前 `backward()` 以标量为根并设置 `loss.grad = 1`；向量输出需要额外指定反向种子。
4. `model.zero_grad()` 清除上一轮参数梯度，`loss.backward()` 生成本轮梯度，参数更新则沿
   负梯度方向修改 `data`。
5. 有限差分把函数当作黑盒，用微小扰动估计梯度，只用于验证，不用于正式训练。
